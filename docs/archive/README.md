# Archived planning documents

These documents were written during the project's planning phase, before implementation:

- `PROJECT_MASTER_SPEC.md`
- `DECISIONS.md`
- `GLOF_PROJECT_ISSUES_AND_GUARDRAILS.md`
- `DATA_DICTIONARY.md`

They describe a larger scope than the one implemented. That scope included IEEE DataPort pretraining, the Lesi et al. inventory as training data, Refined Lee speckle filtering and an AOI at the Passu Glacier front. They are kept for reference only.

**The current method is described in the [main README](../../README.md), in the notebook [`notebooks/glof_pipeline.ipynb`](../../notebooks/glof_pipeline.ipynb) and in the [deliverables](../../reports/deliverables/).**
